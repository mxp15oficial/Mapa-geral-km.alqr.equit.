# Mapa Geral Faz

Aplicativo para medição de fazendas e talhões.

## Funcionalidades
- Medição em hectares
- Medição em km²
- Conversão para alqueires
- Mapa por satélite
- Cadastro de fazendas
- Relatórios PDF
- Assinatura mensal

## Tecnologias
- Flutter
- Supabase
- PostgreSQL/PostGIS
- Mapbox
